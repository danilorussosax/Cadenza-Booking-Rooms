# Font dei cartelli QR

`Inter.ttf` è il font variabile Inter distribuito da [Google Fonts](https://github.com/google/fonts/tree/main/ofl/inter), con licenza SIL Open Font License 1.1 inclusa in `OFL.txt`.

La configurazione `fonts.conf` permette al renderer Sharp/Pango di usare il font incluso anche su server senza font di sistema. Il font serve esclusivamente a comporre i testi: il QR viene generato separatamente e conservato senza sovrapposizioni.
